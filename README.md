# 📚 Hogwarts Reader & Editor

Полноценное PWA-приложение для чтения и редактирования текстов с GitHub-интеграцией.

## ✨ Возможности

### 📖 Режим чтения
- Импорт книг из HTML, TXT, MD файлов
- Автоматическое определение глав
- Навигация по главам
- Полнотекстовый поиск
- Озвучка текста (Web Speech API)
- Выбор голоса и скорости чтения
- Сохранение прогресса

### ✏️ Режим редактирования
- Полноценный WYSIWYG-редактор (как в Word 2016)
- Форматирование текста (жирный, курсив, подчёркивание)
- Заголовки разных уровней
- Списки (маркированные и нумерованные)
- Выравнивание текста
- Цитаты
- Выбор шрифта и размера
- Автосохранение
- Подсчёт слов
- Экспорт в HTML

### 📚 Библиотека
- Управление коллекцией книг
- Импорт из файлов
- Создание новых книг
- Удаление книг
- Метаданные (количество глав, слов)

### 💬 Комментарии
- Добавление комментариев к книгам
- Локальное хранение (localStorage)
- Подготовка к GitHub-интеграции

### 🎨 Интерфейс
- Светлая и тёмная темы
- Адаптивный дизайн (мобильные устройства)
- PWA (устанавливается как десктопное приложение)
- Офлайн-работа

## 🚀 Установка как десктопного приложения

### Chrome / Edge / Brave

1. Откройте приложение в браузере
2. Нажмите на иконку установки в адресной строке (⊕ или 📥)
3. Подтвердите установку
4. Приложение появится в меню Пуск / Launchpad

### Альтернативный способ (Chrome)

1. Откройте меню браузера (⋮)
2. Выберите "Установить Hogwarts Reader & Editor..."
3. Подтвердите установку

## 📦 Развёртывание на GitHub Pages

### Шаг 1: Создайте репозиторий

```bash
# Клонируйте ваш репозиторий
git clone https://github.com/YOUR_USERNAME/hogwarts-app.git
cd hogwarts-app
```

### Шаг 2: Скопируйте файлы

Скопируйте все файлы из папки `hogwarts-app` в корень репозитория:
- `index.html`
- `manifest.json`
- `sw.js`
- `icon-192.svg`
- `icon-512.svg`
- `README.md`

### Шаг 3: Запушьте на GitHub

```bash
git add .
git commit -m "Initial commit: Hogwarts Reader & Editor"
git push origin main
```

### Шаг 4: Включите GitHub Pages

1. Перейдите в репозиторий на GitHub
2. Откройте **Settings** → **Pages**
3. В разделе **Source** выберите:
   - Branch: `main`
   - Folder: `/ (root)`
4. Нажмите **Save**
5. Подождите 1-2 минуты
6. Приложение будет доступно по адресу: `https://YOUR_USERNAME.github.io/hogwarts-app/`

## 🔧 GitHub-интеграция (в разработке)

Для синхронизации книг и комментариев через GitHub:

1. Создайте Personal Access Token:
   - GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
   - Выберете scope: `repo`
   - Скопируйте токен

2. Откройте приложение → Настройки (⚙️)
3. Введите:
   - GitHub Token
   - Имя пользователя
   - Название репозитория для хранения книг

4. Нажмите "Сохранить"

## 🎯 Использование

### Импорт книги

1. Перейдите в режим "Библиотека"
2. Нажмите "📥 Импорт книги"
3. Выберите файл (HTML, TXT, MD)
4. Книга появится в библиотеке

### Создание новой книги

1. Перейдите в режим "Библиотека"
2. Нажмите "✨ Новая книга"
3. Откроется редактор
4. Начните писать

### Чтение книги

1. Перейдите в режим "Библиотека"
2. Нажмите на карточку книги
3. Используйте панель инструментов:
   - ⏮ Назад / Вперёд ⏭ — навигация по главам
   - 🔊 Озвучка — включить/выключить чтение вслух
   - 📖 Оглавление — перейти к списку глав

### Редактирование книги

1. В библиотеке нажмите "Редактировать" на карточке книги
2. Используйте панель инструментов для форматирования
3. Изменения сохраняются автоматически
4. Нажмите "💾 Сохранить" для явного сохранения
5. "📤 Экспорт" — скачать книгу как HTML

### Комментарии

1. Нажмите 💬 в верхней панели
2. Напишите комментарий
3. Нажмите "Отправить"
4. Комментарии сохраняются локально
